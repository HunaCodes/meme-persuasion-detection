Meme Persuasion Technique Detection
A deep learning NLP project that classifies persuasion techniques in meme text and identifies the text spans associated with each technique. Built using Python, PyTorch and transformer-based models.
Features
- Multi-label classification of 20 persuasion techniques
- Text-span detection to highlight where techniques occur
- Evaluation of model performance, potential bias and generalisation
Dataset and access
This project uses data from SemEval-2021 Task 6: Detection of Persuasion Techniques in Texts and Images.

The dataset is not included in this repository. The dataset subset supplied for this university assessment was provided under terms that prohibit sharing, redistribution or use outside the assessment, so I cannot upload or provide a copy of it.

For information about the original public corpus, visit the dataset authors' repository:
- Official dataset repository: https://github.com/di-dimitrov/SEMEVAL-2021-task6-corpus
- Research paper: https://arxiv.org/pdf/2105.09284.pdf
Please check the original authors' terms and licensing before downloading or using any data. The public corpus may differ from the assessment-specific subset used here.
